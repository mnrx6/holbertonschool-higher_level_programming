
# JavaScript DOM Manipulation

## Description
This project covers JavaScript DOM manipulation, event handling, and fetching data from APIs.

## Learning Objectives
- Select HTML elements using `querySelector()`.
- Change text, styles, and CSS classes.
- Handle click events with `addEventListener()`.
- Create and add HTML elements.
- Fetch data from APIs using `fetch()`.
- Work with JSON and Promises.
- Use `DOMContentLoaded`.

## Files
- `0-script.js` - Change the header text color to red.
- `1-script.js` - Change the header color when clicked.
- `2-script.js` - Add the red class to the header.
- `3-script.js` - Toggle between red and green classes.
- `4-script.js` - Add new items to a list.
- `5-script.js` - Update the header text.
- `6-script.js` - Fetch a Star Wars character.
- `7-script.js` - Fetch and display Star Wars movie titles.
- `8-script.js` - Fetch and display Hello in French.

## Technologies
- JavaScript
- HTML
- CSS
- Fetch API

## How to Run
Open the corresponding HTML file in a web browser to test each JavaScript script.
