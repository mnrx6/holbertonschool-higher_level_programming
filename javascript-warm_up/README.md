# JavaScript - Warm up

## Description

This project is part of the Holberton School curriculum. It introduces JavaScript fundamentals through scripting exercises using Node.js.

## Learning Objectives

- Understand JavaScript basics and data types.
- Use variables (`let`, `const`, `var`).
- Work with operators and conditions.
- Use loops (`for`, `while`).
- Create and use functions.
- Work with arrays and objects.
- Handle command-line arguments.
- Import and export modules.

## Requirements

- Node.js 14.x
- Ubuntu 20.04 LTS
- Semistandard 16.x
- All files must be executable.
- All scripts must start with `#!/usr/bin/node`.

## Usage

Run a script:

```bash
node filename.js
```

Check code style:

```bash
semistandard *.js
```
